## 更新内容

- 项目页支持一次导入多个本机项目目录。移除导入记录不会删除磁盘文件。
- 主面板右上角可直接重启本地网关，悬停可查看按钮用途。重启超时可重试，更新安装期间不会因重启而中断。
- 会话索引按变化分批更新，中断后可续扫；空闲时减少扫描，主动打开列表时按需刷新。
- 完成通知和额度告警跟随 Agent 主题色，暗色自动提亮。超过一分钟的事件不再补弹或响铃，不影响最近完成记录。
- 优化面板首次打开时的布局；修复手动检查更新时安装入口被遮挡、安装助手启动失败仍显示安装中的问题。改善本地安装回滚和 Codex 通知配置恢复。
