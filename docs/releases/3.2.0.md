## 更新内容

- 修复概览近 24 小时用量趋势：多个可见 Agent 各自按主题色绘制曲线，共用同一纵轴，可直接比较；Antigravity 缺少采样的时段不连线。
- 调整项目页操作图标和用量页 CSV 导出图标的尺寸，使其与相邻控件协调。

- Antigravity 加入概览、会话、项目和用量页，面板显示、菜单栏和主题色可独立设置。未安装时默认隐藏，已有设置保持不变。
- 桌面端可搜索本地会话摘要；CLI 可恢复各工作目录缓存的最近会话。桌面会话需先在 CLI 中手动导入，AgentDeck 不读取聊天正文。
- 手动启用 [CLI 状态行适配器](https://github.com/Spacebody/AgentDeck/blob/v3.2.0/docs/antigravity.md) 后，可查看官方上报的额度和采样后的 token 增量。不回填启用前的历史，也不估算成本。
- 可选的 [生命周期钩子](https://github.com/Spacebody/AgentDeck/blob/v3.2.0/docs/antigravity-lifecycle.md) 提供活跃状态和完成提醒。升级不会自动修改 Antigravity 配置。
