## 更新内容

- 全新原生面板，分为概览、会话、项目和用量四页。概览同时展示今日 token、账号额度和最近完成的工作。
- 会话支持搜索、分页和恢复；项目页按目录汇总会话。工作状态灯跟随 Agent 配色，开启系统“减少动态效果”时保持静态。
- 今日圆环按可见 Agent 的实际用量分段。用量页可比较近 7 天和 30 天的数据，按项目查看排行，或导出 CSV。Qoder CN 独立统计。
- Agent 管理支持 RGB 与十六进制调色。面板内图标、额度与统计图同步换色；菜单栏恢复系统单色，保留额度告警色。
- 修复设置页暗度被背景遮盖、项目页忽略刷新间隔与活跃卡片开关，以及自定义间隔显示与保存不一致的问题。
